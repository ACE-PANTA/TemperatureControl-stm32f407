### 网络直连 PC

默认 **静态 IP**（无 DHCP）：

1. 网线直连 STM32 和 PC，确认 LAN8720A 旁 Link LED **常亮**
2. PC 设置静态 IP：`192.168.1.10`，掩码 `255.255.255.0`
3. `ping 192.168.1.100` 验证
4. `nc 192.168.1.100 8000` 连接

接路由器时需保证 `192.168.1.x` 网段，`192.168.1.100` 未被占用。否则用 `!NET=...` 改 IP 后 `!SAVE`。

## 2. 控制架构

### 双模 PID 控制器

热系统有**大时延**：加热器通电后要过几十秒 NTC 才能感知到温度变化，而且关掉加热后温度还会继续上升（热惯性）。

**模式 1 — 位置式 PID（变温模式）：**
```
u = Kp × e + Ki × ∫e·dt + Kd × de/dt
```

- **Ki 积分项消除稳态误差**，不会永远差一点到不了目标
- 积分抗饱和：PWM 到 0% 或 100% 时冻结积分
- 当 |误差| > `tran_sep_threshold` 时清零积分，避免大误差阶段积分堆积
- 每 `tran_interval` 秒调节一次（默认 3 秒，需 ≥ 系统时延）

**稳定性检测（默认 20 秒滑动窗口）：**

- 每秒记录当前温度到环形缓冲区
- 最近 `stable_window` 秒内温度波动 ≤ `stable_delta` → 判定为"基本稳了"
- 当前版本微调入口不再依赖稳定性检测；窗口数据保留用于诊断和后续扩展

**模式 2 — 融合微调 PID（微调模式）：**

触发条件：`fine_enable=1` 且 `|误差| <= fine_entry_max`

```
Δu = Kp × [e(k)-e(k-1)] + Ki × e(k) × Ts + Kd × [e(k)-2e(k-1)+e(k-2)]
增量式输出 = 上一次输出 + Δu
位置式输出 = tran_kp × e + tran_ki × ∫e·dt + tran_kd × de/dt
最终输出 = 位置式输出 × w + 增量式输出 × (1-w)
```

- 微调区同时计算位置式和增量式，两者都参与输出
- 越接近目标温度，位置式权重越高；越远离目标，增量式权重越高
- 位置式权重限制在 20%~75%，避免慢热、大时延系统被位置式单独接管后突变
- `Δu` 和最终融合输出都受 `fine_range` 限制，不会一下变太多
- 微调工况下 PWM 下限为 0，不启动风扇；变温工况仍可输出负 PWM 控制风扇
- 死区内不退出微调，也不把 PWM 置 0，而是保持上一轮 PWM
- 退出条件：`|误差| > 2.5 × fine_entry_max`

注意：

- `FINE` 不是手动切换出来的模式，不能直接发送 `!MODE=FINE`
- `!FINEEN=0` 会禁用微调工况，自动模式一直保持 `TRAN`
- `fine_entry_min` 不再作为微调入口下限；它用于近区位置式限速辅助范围
- 如果你感觉“现在改不了了”，通常不是收发格式错了，而是当前模式限制了可改对象：自动模式改 `TEMP`，手动模式改 `PWM`

### 工况切换流程

```text
每秒执行一次:
1. 采样当前温度 temp_feedback
2. 手动模式:
   直接使用 temp_ctr_val，不进入 PID 切换
   当前工况 = MAN
3. 自动模式:
   对误差做一阶低通滤波
   若 fine_enable=1 且 |error| <= fine_entry_max:
      进入微调工况 FINE
   若 fine_enable=0 或尚未进入微调:
      保持变温工况 TRAN
   若已在 FINE 且 |error| > 2.5 * fine_entry_max:
      无扰切换回 TRAN
   若 |error| <= pid_deadband:
      保持当前 PWM，不更新输出
4. 输出 PWM
5. 主动上报当前数据，再追加上报当前工况
```

工况含义：

- `MAN`：手动模式，直接输出手动 PWM
- `TRAN`：自动模式下的变温工况，使用位置式 PID 做主调节，可输出负 PWM 控制风扇
- `FINE`：自动模式下的微调工况，融合位置式和增量式 PID，小步修正且不启动风扇

## 3. 参数表

### A. 系统控制

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `manual_flag` | 1 (手动) | 0/1 | 0=自动温控, 1=手动 PWM |
| `target_temp` | 30.0 | -10~100 °C | 自动模式目标温度 |
| `manual_pwm` | 0 | -100~100 | 手动 PWM 值 |
| `step_value` | 1 | 1/5/10 | 按键步进量 |

### B. 变温工况 — 位置式 PID（主力）

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `tran_kp` | 3.0 | 0.1~50 | 比例增益 |
| `tran_ki` | 0.3 | 0~5 | 积分增益（消除稳态误差） |
| `tran_kd` | 1.0 | 0~10 | 微分增益（阻尼防过冲） |
| `tran_interval` | 3 | 1~60 秒 | 调节间隔 |
| `tran_sep_threshold` | 10.0 | 1~30 °C | 积分分离阈值：误差超此值清零积分 |

### C. 微调工况 — 融合 PID

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `fine_enable` | 1 | 0/1 | 1=启用微调工况, 0=禁用微调并一直保持 TRAN |
| `fine_kp` | 1.5 | 0.1~20 | 比例增益（更保守） |
| `fine_ki` | 0.1 | 0~3 | 积分增益 |
| `fine_kd` | 2.0 | 0~10 | 微分增益（更强调阻尼） |
| `fine_interval` | 8 | 1~60 秒 | 调节间隔（更慢，等系统响应） |
| `fine_range` | 5.0 | 1~20 % | 单次最大变化（更紧） |
| `fine_entry_min` | 1.0 | 0.1~5 °C | 近区位置式限速辅助范围 |
| `fine_entry_max` | 3.0 | 1~10 °C | 进入微调的最大误差；退出阈值为 2.5 倍 |
| `stable_window` | 20 | 10~120 秒 | 稳定性检测窗口长度（当前不作为微调入口条件） |
| `stable_delta` | 1.0 | 0.2~5.0 °C | 窗口内最大波动，低于此值判稳 |

### D. 共享

| 参数 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `pid_deadband` | 0.3 | 0.1~2.0 °C | 死区宽度 |

### E. 网络

| 参数 | 默认值 | 说明 |
|---|---|---|
| `eth_ip` | 192.168.1.100 | 静态 IP（重启生效） |
| `eth_gateway` | 192.168.1.1 | 网关（重启生效） |
| `eth_netmask` | 255.255.255.0 | 子网掩码（重启生效） |
| `tcp_port` | 8000 | TCP 端口（重启生效） |
| `eth_mac` | 02:00:00:00:00:01 | MAC 地址（重启生效） |

## 4. 指令协议

### 帧格式

```
请求: !CMD=VALUE*XX\r\n
回复: !ACK=OK*XX\r\n      (成功)
      !ACK=ERR*XX\r\n     (失败)
      !响应内容*XX\r\n    (查询结果)
```

- `!` 帧头，`*XX` 异或校验和，`\r\n` 帧尾
- **串口 (USART1) 和网口 (TCP:8000) 协议完全相同**

### 系统控制

| 指令 | 示例 | 说明 |
|---|---|---|
| `!MODE=AUTO` | `!MODE=0*34\r\n` | 切换到自动温控 |
| `!MODE=MAN` | `!MODE=1*35\r\n` | 切换到手动 PWM |
| `!TEMP=58.0` | `!TEMP=58.0*15\r\n` | 设置目标温度 |
| `!PWM=50` | `!PWM=50*12\r\n` | 设置手动 PWM（仅手动模式） |
| `!STEP=5` | `!STEP=5*13\r\n` | 设置按键步进 (1/5/10) |

### PID 调参

| 指令 | 示例 | 说明 |
|---|---|---|
| `!TRAN=3.0,0.3,1.0` | 变温基础 | 设 Kp, Ki, Kd |
| `!TRAN=3.0,0.3,1.0,3,10` | 变温全部 | 也设间隔和积分分离阈值 |
| `!FINE=1.5,0.1,2.0` | 微调基础 | 设 Kp, Ki, Kd |
| `!FINE=1.5,0.1,2.0,8,5,1,3,20,1.0` | 微调全部 | 也设间隔/限幅/入口阈值/稳定窗口/稳定阈值 |
| `!FINEEN=1` | 微调开关 | 1=启用微调, 0=禁用微调 |
| `!DEADBAND=0.3` | 死区 | 设死区宽度 |

### 网络（修改后需重启）

| 指令 | 示例 |
|---|---|
| `!NET=192.168.1.100,192.168.1.1,255.255.255.0,8000` | 设 IP/网关/掩码/端口 |
| `!MAC=02:00:00:00:00:01` | 设 MAC 地址 |

### 查询

| 指令 | 回复示例 |
|---|---|
| `!GET=STATE` | `STATE=MODE:0,PHASE:TRAN,PWM:35,GOAL:580,FB:575` |
| `!GET=TRAN` | `TRAN=KP:3.00,KI:0.300,KD:1.00,INT:3,SEP:10.0` |
| `!GET=FINE` | `FINE=EN:1,KP:1.50,KI:0.100,KD:2.00,INT:8,FR:5.0,EMIN:1.0,EMAX:3.0,SW:20,SD:1.0` |
| `!GET=FINEEN` | `FINEEN=1` |
| `!GET=DEADBAND` | `DEADBAND=0.30` |
| `!GET=PID` | 返回 TRAN + FINE + DEADBAND 三行 |
| `!GET=NET` | `NET=IP:192.168.1.100,GW:192.168.1.1,NM:255.255.255.0,PORT:8000` |
| `!GET=ETH` | `ETH=LINK:1,PHY:0,ERR:0,PHYID:0007C0F1,RX:5,TX:5,ARP:2,ICMP:3,TCP:0` |
| `!GET=CONFIG` | 逐条返回全部配置参数 |

### 持久化
 
| 指令 | 说明 |
|---|---|
| `!SAVE` | 立即保存当前配置到 Flash |
| `!RESET` | 恢复出厂默认值（保留 MAC） |

> 参数修改后自动延迟 500ms 保存。`!SAVE` 强制立即保存。

## 5. STATE 字段说明

`!GET=STATE` 返回：

```
STATE=MODE:0,PHASE:TRAN,PWM:35,GOAL:580,FB:575
```

设备在每秒数据上报后，还会主动追加一帧当前工况：

```
PHASE=MAN
PHASE=TRAN
PHASE=FINE
```

| 字段 | 含义 | 说明 |
|---|---|---|
| MODE | 模式 | 0=自动, 1=手动 |
| PHASE | 当前工况 | MAN=手动, TRAN=变温, FINE=微调 |
| PWM | 当前 PWM | -100~100, 正=加热, 负=风扇 |
| GOAL | 目标×10 | 如 580 = 58.0°C |
| FB | 反馈×10 | 如 575 = 57.5°C |

### 主动上报顺序

每秒周期内，设备会按下面顺序主动发送：

1. DataScope 二进制采样数据（USART1）
2. `PHASE=...` 文本帧（USART1）
3. `STATE=...` 文本帧（TCP 已连接时）
4. `PHASE=...` 文本帧（TCP 已连接时）

### ETH 诊断 (GET=ETH)

```
ETH=LINK:1,PHY:0,ERR:0,PHYID:0007C0F1,RX:5,TX:5,ARP:2,ICMP:3,TCP:0
```

| 字段 | 含义 |
|---|---|
| LINK | 1=网线已连接, 0=未连接 |
| PHY | PHY 芯片地址 (0/1, 255=未找到) |
| ERR | 错误码 (0=正常) |
| PHYID | 芯片型号 (0007C0F1=LAN8720A) |
| RX | 收包数 |
| TX | 发包数 |
| ARP | ARP 回复数 |
| ICMP | Ping 回复数 |
| TCP | 1=有客户端, 0=无客户端 |

### 以太网错误码

| 码 | 名称 | 含义 | 解决 |
|---|---|---|---|
| 0 | `ETH_ERR_OK` | 正常 | — |
| 1 | `ETH_ERR_NO_PHY` | 找不到 PHY | 检查焊接/供电/晶振 |
| 2 | `ETH_ERR_NO_LINK` | 网线未连接 | 检查网线、对端上电 |
| 3 | `ETH_ERR_ANEG_TIMEOUT` | 自协商超时 | 检查 50MHz RMII 时钟 |
| 4 | `ETH_ERR_NOT_INITED` | ETH 未初始化 | 检查 eth.c 是否编译 |

## 6. 快速开始

### 首次上电

```
1. 默认手动模式，目标 30°C
2. 连接串口 (115200 8N1) 或 TCP (nc 192.168.1.100 8000)
3. 发送 !MODE=AUTO
4. 发送 !TEMP=58.0
5. 观察：PWM 每隔 pid_interval 秒调节一次
```

### 调参指南

```
1. 变温工况（位置式 PID）：
   !TRAN=3.0,0.3,1.0,3          (默认值)
   升温太慢              → 增大 tran_kp (3→5) 或 tran_ki (0.3→0.6)
   超调严重              → 增大 tran_kd (1→3) 或增大 tran_interval (3→5)

2. 微调工况（融合 PID）：
   !FINEEN=1                    (启用微调；!FINEEN=0 可禁用)
   !FINE=1.5,0.1,2.0,8,5        (默认值)
   接近目标后仍振荡       → 减小 fine_range (5→3) 或增大 fine_interval (8→10)
   稳住了但还差 1°C      → 保持微调开启，融合输出会小步逼近
   微调幅度太大           → 减小 fine_range (5→3)
   微调反应太慢           → 减小 fine_interval (8→5)

3. 死区：
   !DEADBAND=0.3
   目标附近小幅振荡       → 增大 deadband (0.3→0.5)

4. 保存：
   !SAVE
```

## 8. 故障排查

| 现象 | 可能原因 | 解决 |
|---|---|---|
| 温度卡在目标以下 | Ki 太弱 / max_delta 太小 | 增大 Ki (0.3→0.6) 或 max_delta (8→12) |
| 超调严重 | Kp 太大 / Kd 太小 / 间隔太短 | 减小 Kp，增大 Kd，增大 pid_interval |
| PWM 剧烈振荡 | max_delta 太大 / 间隔太短 | 减小 max_delta (8→4)，增大间隔 (5→10) |
| 目标附近小幅振荡 | 死区太小 | 增大 pid_deadband (0.3→0.5) |
| 对误差无反应 | pid_interval 太长 | 减小 pid_interval |
| 网口连不上 | IP 不匹配 / 硬件问题 | 串口发 `!GET=ETH` 诊断 |
| Flash 保存失败 | 扇区擦写错 | 检查 FLASH_Sector_7 未被占用 |
